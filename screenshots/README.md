# EduGuide AI – Personalized Learning Assistant

## 🎓 Project Overview

EduGuide AI is an AI-powered Personalized Learning Assistant designed to support students with study guidance, learning resources, career guidance, learning roadmaps, and interview preparation.

The project is aligned with **Sustainable Development Goal 4 (SDG 4) – Quality Education**.

## 🌍 SDG Alignment

### SDG 4 – Quality Education

EduGuide AI supports SDG 4 by providing accessible educational guidance and helping learners with study planning, learning resources, skill development, career preparation, and structured learning roadmaps.

## ❗ Problem Statement

Students often face difficulties finding suitable learning resources, managing study time, identifying the skills required for different careers, and understanding how to follow a structured learning path.

EduGuide AI addresses this challenge by providing educational and career-related guidance through an interactive AI chatbot.

## 🎯 Project Objective

The main objective of EduGuide AI is to provide students with an accessible AI learning assistant that can:

- Provide study guidance
- Support exam preparation
- Provide time-management tips
- Recommend learning resources
- Generate learning roadmaps
- Provide career guidance
- Recommend career-specific skills
- Provide interview preparation guidance
- Support learning goals
- Handle unrelated questions using a fallback response

## ✨ Key Features

### 📚 Study Guidance
Provides practical study and exam preparation suggestions.

### 🗓️ Study Planning
Helps students organize their learning and manage study time.

### 🧠 Learning Resources
Recommends useful educational platforms and resources.

### 🛣️ Learning Roadmaps
Provides structured learning paths for technical careers such as AI/ML and Data Analytics.

### 💼 Career Guidance
Provides information about career options and required skills.

### 🎤 Interview Preparation
Provides guidance for technical and HR interview preparation.

### 🎯 Learning Goals
Helps students create clear and achievable learning goals.

### 🔄 Fallback Handling
Redirects users when they ask questions outside the chatbot's educational and career-related purpose.

## 🛠️ Technology Stack

- **Botpress Cloud** – Chatbot development and deployment
- **Artificial Intelligence** – Intelligent conversational assistance
- **Natural Language Processing (NLP)** – Understanding user queries
- **Knowledge Base** – Educational information and resources
- **Webchat** – User interaction interface
- **GitHub** – Project documentation and repository
